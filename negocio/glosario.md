# Glosario

> **Documento ficticio para el workshop de Kiro.**

| Término | Definición |
| --- | --- |
| Frutas y verduras (FyV) | Sección de la tienda con productos frescos sin procesar |
| Pérdida (merma) | Producto recibido que no se vende ni se transforma: se descarta o se dona |
| Etapa de madurez | Verde, pintón, maduro o sobremaduro, según los umbrales del catálogo |
| Índice de madurez | Número de 0 (totalmente verde) a 100 (pasado) que estima el modelo de visión |
| Umbral | Valor del índice donde empieza una etapa; un índice igual al umbral ya pertenece a esa etapa |
| Punto óptimo | Momento en que el producto entra a la etapa madura |
| Confianza | Qué tan seguro está el modelo de su lectura, de 0 a 1 |
| Revisión humana | Caso que una persona debe confirmar porque la confianza es baja o la acción lo exige |
| Transformar | Llevar el producto a producción interna: jugos, pulpa, panadería o salsas |
| Ronda de la mañana | Recorrido diario del auxiliar por la góndola para decidir qué hacer con cada producto |
| Acierto | Porcentaje de fotos etiquetadas en las que el analizador da la etapa correcta |
