# Política de acciones en tienda para frutas y verduras

> **Documento ficticio para el workshop de Kiro.** No refleja políticas reales de ninguna empresa.

**Código:** POL-FRV-001 · **Versión:** 1.0 · **Área responsable:** Operaciones de frescos

## 1. Objetivo

Que todas las tiendas tomen la misma decisión ante el mismo producto, para reducir la pérdida y no vender productos que no cumplen la calidad esperada.

## 2. Acciones posibles

| Acción | Qué significa en la tienda |
| --- | --- |
| **Mantener** | El producto sigue en góndola a su precio normal |
| **Priorizar** | El producto está en su punto: se exhibe al frente para que se venda primero |
| **Rebajar** | Se aplica un descuento del 30% y se marca con la etiqueta de "consumo inmediato" |
| **Transformar** | Se retira de góndola y se envía a producción interna (jugos, pulpa, panadería o salsas, según el producto) |
| **Donar** | Se retira y se entrega el mismo día al banco de alimentos, con confirmación del jefe de sección |
| **Retirar** | Se descarta. No se vende, no se transforma y no se dona |
| **Revisar** | Una persona debe revisar el producto antes de decidir |

## 3. Reglas, en este orden

La primera regla que se cumple decide la acción.

1. Si la confianza del análisis es **menor a 0,70**, o no se reconoció el producto: **Revisar**.
2. Si el producto tiene **moho**: **Retirar**.
3. Si está **verde** o **pintón**: **Mantener**.
4. Si está **maduro**: **Priorizar**.
5. Si está **sobremaduro** y las manchas cubren **menos del 30%** de la superficie, sin zonas hundidas: **Rebajar**.
6. Si está **sobremaduro** y las manchas cubren **del 30% al 59%**, o tiene zonas hundidas: **Transformar**.
7. Si está **sobremaduro** y las manchas cubren **el 60% o más**: **Donar**.

## 4. Mensaje para el personal

Cada recomendación incluye un texto corto que explica la acción, por ejemplo: "Rebajar 30% y etiquetar como consumo inmediato". Para **Transformar**, el texto indica el destino según el producto (por ejemplo, "Enviar a jugos o pulpa" para el mango).

## 5. Registro

Toda acción queda registrada con la tienda, el producto, la etapa y la acción recomendada. Las acciones **Donar** y **Revisar** requieren la confirmación del jefe de sección.

## 6. Indicadores

| Indicador | Meta |
| --- | --- |
| Productos rebajados que se venden antes del cierre | Más del 70% |
| Casos "Revisar" resueltos el mismo día | 100% |
| Pérdida total de la sección | Menos del 6,5% |
